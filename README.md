# The Phoenix Project

Revamped Prostate Cancer Foundation of New Zealand (PCFNZ) website.

## GitHub Pages Link
```
https://Tyelk.github.io/The_Phoenix_Project
```

## Features

- Clear and minimal page redesign
- Improved navigation with related page sidebars
- Prostate Puzzle - a multiple-choice quiz game for prostate knowledge
- Responsive pages that adjust content for different screen sizes

## How to Setup

The website can be viewed locally by running the following commands:

### 1. Clone the Repository

```
git clone https://github.com/Tyelk/The_Phoenix_Project.git
cd The_Phoenix_Project
```

### 2. Install Dependencies

```
npm install
```

### 3. Build Project

```
npm run build
```

### 3. Run Preview

```terminal
npm run preview
```

## Other Commands

The app can alternatively be run with the following command:

### Run Project

```
npm run dev
```
